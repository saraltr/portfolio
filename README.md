# 🎨 Web Design & Development Portfolio

Welcome to my personal portfolio!  
This project showcases a selection of my work as a web developer, highlighting projects that explore UI/UX, and visual design, alongside practical applications of HTML, CSS, JavaScript, TypeScript, React, Next.js, Blazor, Node.js, and REST/GraphQL APIs.

## ✨ Overview

This portfolio is both a professional showcase and a creative space where I experiment with styles, layouts, and themes.

## 🛠️ Tech Stack

- **Framework:** Next.js / React
- **Styling:** Tailwind CSS
- **Languages:** TypeScript, HTML, CSS
- **Image Optimization:** Next.js `<Image />`
- **Deployment:** Vercel

## 🎯 Features

- Responsive and accessible layouts
- Dynamic components and animations
- Visually diverse projects exploring different design aesthetics and concepts
- Pages organized by project and design focus
- Includes both development and design-focused content

## 🚀 Getting Started

To run this project locally:

This is a [Next.js](https://nextjs.org/) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
